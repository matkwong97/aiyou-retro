Diagnostics and troubleshooting

The emulator may download its engine when launched. On iPhone, tap the emulator's own Start Game button if shown. Use the emulator’s on-screen gamepad for Start and Select. Exit game is always available above the player.

In-game saves and emulator save states are different. Export backups from the emulator menu. Real link-cable trading is not implemented in this release.
